## 新增：睡觉看视频定时关机/休眠工具（Python）

文件：`sleep_video_timer.py`

### 功能
- 主界面可分开选择小时和分钟（24小时制），并可直接输入；同时可选动作（休眠/关机）。
- 点击设定后会提示“设定成功”，并最小化到任务栏。
- 到目标时间前 30 秒会自动弹出窗口，提醒你如果还醒着可重新设定。
- 如果 30 秒内没有操作，到时间自动执行休眠或关机。
- 每次设定时，默认时间都会设为“当前时间 + 1 小时”（小时和分钟都会更新）。

### 运行方式
```bash
python3 sleep_video_timer.py
```

> 注意：真正执行休眠/关机会调用系统命令，请先在测试环境验证。
